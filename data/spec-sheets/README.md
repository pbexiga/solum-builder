# Datasheets

The datasheets behind the model library (D-149). The PDFs are kept on this machine only (gitignored, since most makers don't allow redistribution); this index is committed. `python3 scripts/fetch_spec_sheets.py` downloads any sheet listed here that's missing. A link that always serves the maker's latest revision may give a newer file than the one named here; the revision the model records cite is in the filename.

Values read from a sheet go into the model's record in `library/models/<type>/<ID>.json` (`rating_sources`, `validation`, `package.source`), cited by document number.

## Shipped

Every model in `library/models/`, written from the records by `python3 scripts/models_index.py` (a unit test fails when it's out of date). **Licence** is the review of the file each model came from: *Settled*, or *Decide* where shipping it waits for the user (D-156). A model we fitted ourselves says "Solum Builder fit" in Model by. **Card** says plainly whose card it is: *Ours (fitted from* the sheet*)*, or *Pulled (*the library or analysis it came from*)*.
