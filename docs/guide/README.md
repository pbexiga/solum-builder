# Solum Builder guide

Solum Builder is a circuit simulator for guitar-pedal builders. You draw a circuit, probe any point in it, turn its knobs and watch the curves follow, check it against plain-English rules, and hear it through an amp model. It runs on your own computer; nothing is sent anywhere.

This guide opens in the app from **Help → Documentation**. Type in the search box to find a section on any page.
